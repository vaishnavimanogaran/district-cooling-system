# District Cooling System

A Spring Boot + MySQL application for managing district cooling operations.

## Features

- Chiller Plant Management
- Customer Management
- Vendor Management
- Telemetry Monitoring
- Automatic Ton-Hour Calculation
- Invoice Generation
- Profit & Loss Report
- Budget Performance Report

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Swagger UI
- Postman
