# ❄️ District Cooling System

A full-stack web application for managing a **District Cooling System**. This project helps administrators manage customers, chiller plants, vendors, generate invoices, and view operational reports through a simple dashboard.

## 📌 Features

- 🔐 Admin Login
- 👥 Customer Management (Add & View)
- 🏭 Chiller Plant Management
- 🚚 Vendor Management
- 🧾 Invoice Generation
- 📊 Dashboard & Reports
- 💾 MySQL Database Integration

## 🛠️ Tech Stack

| Layer | Technology |
|--------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Spring Boot |
| Database | MySQL |
| API Testing | Swagger / REST API |

## ⚙️ How to Run

### Backend

1. Open the Spring Boot project in STS/Eclipse.
2. Configure MySQL in `application.properties`.
3. Run the application.
4. Backend starts at:

```text
http://localhost:8080
```

### Frontend

1. Open the `frontend` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `login.html` → **Open with Live Server**.
